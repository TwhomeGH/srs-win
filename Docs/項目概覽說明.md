# SRS (Simple-Rtmp-Server) Windows 移植版 — 項目概覽

## 專案簡介

SRS 是一個高效能的即時影音串流伺服器，支援 RTMP、WebRTC、HLS、HTTP-FLV、SRT、GB28181 等多種協議。
本專案為 SRS v7.0.89 的 **Windows 原生移植版**，使用 **MSVC (Visual Studio 2022)** 編譯工具鏈，
替代官方的 Linux `configure`/`make` 建置流程。

> 官方 SRS 已在 v7.0.60+ 移除 Windows 支援，理由為維護成本過高，建議使用 WSL/Docker。
> 此 Fork 為獨立維護的 Windows 原生版本。

```
│   │   ├── main/                  # 進入點（main, daemon, server）

│   │   └── rtc/                   # WebRTC 支援
│   ├── ide/
│   │   └── srs_msvc/              # MSVC 建置基礎設施（← Windows 移植核心）

│   │       ├── ffmpeg_stubs/      # FFmpeg API Stub（避免真實 FFmpeg 相依）
│   │       └── build/             # 建置輸出（srs.exe）
│   ├── 3rdparty/
│   │   └── st-srs/                # State Threads 程式庫（← 含 Windows ASM 移植）
│   ├── conf/                      # 設定檔

├── rebuild.ps1                    # 一鍵建置 + 執行 PowerShell 腳本
├── stop.ps1                       # 停止 SRS 行程
└── trunk/ide/srs_msvc/build/Debug/srs.exe  # 已編譯的二進位檔（7+ MB）
```

### 🔄 支援的協議

- **RTMP** (發佈/播放, SRT <-> RTMP 橋接)
- **HTTP-FLV / HTTP-TS / HLS / HDS**
- **WebRTC (RTC)** (WHIP/WHEP, 含 SRTP/SCTP/DTLS)
- **SRT** (可靠的 UDP 傳輸)
- **GB28181** (中國安防監控協議)
- **MPEG-DASH**
- **DVR** (錄影至 FLV/MP4)
- **Prometheus Exporter**
