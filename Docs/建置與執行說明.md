# SRS Windows 版 — 建置與執行說明

## 環境需求

| 項目 | 需求 |
|------|------|
| **作業系統** | Windows 10/11 x64 |
| **編譯器** | Visual Studio 2022 (Community/Professional/Enterprise) 含 MSVC v143 |
| **CMake** | 3.15+ |
| **vcpkg** | 建議安裝於 `C:\vcpkg` |
| **MASM** | `ml64.exe` (隨 VS 2022 安裝) |

## 一鍵建置執行

```powershell
# 建置（不執行）
.\rebuild.ps1

# 建置並執行
.\rebuild.ps1 -Run

# 只執行（不重新建置）
.\rebuild.ps1 -Run -NoBuild

# 停止 SRS
.\stop.ps1
```

## 手動建置步驟

### 1. 安裝相依套件（vcpkg）

```powershell
# Install vcpkg if not already:
# git clone https://github.com/Microsoft/vcpkg.git C:\vcpkg
# & C:\vcpkg\bootstrap-vcpkg.bat

# Install required packages:
vcpkg install openssl srtp opus srt --triplet x64-windows
```

### 2. CMake Configure

```powershell
cmake -B trunk/ide/srs_msvc/build `
      -S trunk/ide/srs_msvc `
      -G "Visual Studio 17 2022" -A x64 `
      -DCMAKE_TOOLCHAIN_FILE="C:\vcpkg\scripts\buildsystems\vcpkg.cmake"
```

> 若未使用 vcpkg，部分功能會自動降級（SSL、RTC、SRT 等將被停用）。

### 3. MSBuild

```powershell
msbuild trunk/ide/srs_msvc/build/srs.sln /p:Configuration=Debug /m
```

或使用 CMake:
```powershell
cmake --build trunk/ide/srs_msvc/build --config Debug
```

### 4. 執行

```powershell
.\trunk\ide\srs_msvc\build\Debug\srs.exe -c .\trunk\ide\srs_msvc\build\Debug\live.conf
```

## 設定檔說明

預設設定檔：`trunk/conf/test.conf`（建置時會複製到輸出目錄）。

常用設定調整：

```conf
# 監聽埠
listen              1935;       # RTMP
http_server         8080;       # HTTP API + HLS
https_server        8088;       # HTTPS
rtc_server          8000;       # UDP (WebRTC)
srt_server          10080;      # SRT

# 工作目錄
work_dir            ./objs;

# 日誌
log_level           trace;
log_file            ./objs/srs.log;

# RTC 設定
rtc {
    enabled         on;
    candidate       $CANDIDATE;  # 設為實際 IP
}
```

> **注意**: 設定檔中的路徑請使用正斜線 `/` 或跳脫反斜線 `\\`。

## 驗證服務是否正常

```powershell
# 查看 SRS 是否在執行
Get-Process -Name srs

# 測試 HTTP API
curl http://localhost:8080/api/v1/versions

# 測試 RTMP 推流 (需另裝 ffmpeg)
ffmpeg -re -i video.mp4 -c copy -f flv rtmp://localhost/live/stream

# 測試 RTMP 播放
ffplay rtmp://localhost/live/stream
```

## 開發建議

### Visual Studio 整合

```powershell
# 直接產生 VS 方案並開啟
cmake --open trunk/ide/srs_msvc/build
```

### Debug 技巧

1. **日誌層級**: 設 `log_level debug` 或 `log_level verbose` 以取得更多資訊
2. **PDB 符號**: `srs.pdb` 已隨 build 產生，可用 VS 或 WinDbg 附加偵錯
3. **stderr 輸出**: 錯誤訊息預設輸出至 stderr，可導向檔案：
   ```powershell
   .\srs.exe -c live.conf 2> srs_err.log
   ```

### 清除重建

```powershell
Remove-Item -Recurse -Force trunk/ide/srs_msvc/build
# 然後重新執行 rebuild.ps1
```
